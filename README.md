## Featured projects
 
### [Deadline](https://github.com/gabehowell11/BGSU-2026-hackathon)
**JavaScript · React · Electron · Node.js · SQLite · Tailwind CSS · Aivana API**
 
AI-powered desktop planner for students, built by a team at the 2026 BGSU Hackathon. Upload a
syllabus, schedule, or photo of a handout and Deadline pulls out every due date, exam, and
holiday for you to review, then tracks them in a calendar and a sortable assignment list.
 
- Came up with the idea and the name, helped build the Electron/Node.js backend and SQLite
  database, and overhauled the React frontend
- Built-in AI assistant with streaming replies and structured JSON output that can add, move,
  or complete items, but only after the user confirms
- Cuts token usage by converting documents to plain text and caching extractions, and exports
  to Google Calendar and Outlook through .ics files
[README](https://github.com/gabehowell11/BGSU-2026-hackathon#readme)
 
### [Roster Manager](https://github.com/gabehowell11/roster-manager)
**Python · PySide6 (Qt) · SQLite · pytest · GitHub Actions · Claude Code**
 
Windows desktop app that downloads real NFL depth charts or imports custom rosters, then shows
offense, defense, and special teams as interactive player cards on a football field.
 
- Four-layer architecture (UI, services, data, models) with an offline SQLite database
- 338 automated tests, strict type checking, and CI that builds, installs, and tests a
  one-click Windows installer before every release
- Built with an AI coding agent across 23 issues and 36 pull requests; the README covers
  what the AI got wrong and how I worked around it
[**Download for Windows**](https://github.com/gabehowell11/roster-manager/releases/latest/download/RosterManagerSetup.exe) ·
[README](https://github.com/gabehowell11/roster-manager#readme)
